# GLOWM UX case study

A portfolio case study about literature research and platform comparisons carried out as a research assistant.

This is a static website. GitHub Pages serves `index.html` from the root of the `main` branch.

Original GLOWM screens are shown as research references. Suggested improvements have not yet been user tested.

# Drexel Works — UX/UI Case Study

A portfolio case study exploring a clearer way for Drexel students to find campus jobs, check eligibility, apply, and follow their applications.

## View locally

Open `index.html` in a browser. No build tools or installation are required.

- `index.html` — current case-study homepage
- `scroll-sample.html` — the same case study, retained for existing internal links
- `ideation.html` — design process and early ideas
- `case-study*.css` — shared, main-page, and responsive presentation styles
- `case-study.js` — screen carousel, swipe controls, and active section navigation
- `case-study-nav.js` — floating navigation visibility
- `assets/` — the images, illustrations, and local animation dependency used by these pages

Google Fonts loads Nunito Sans when an internet connection is available. System-font fallbacks are included. GSAP 3.13.0 is included locally with its original license notice.

## Future links

The closing buttons for the next case study and portfolio website are intentionally disabled until their URLs are supplied. Early-design image placeholders remain on the ideation page.

## Hosting
